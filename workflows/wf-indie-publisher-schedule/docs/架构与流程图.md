# 定时发布 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：多平台发布与数据回捞助理 的使用者"]
  T["触发层：定时发布"]
  X["执行层：3 个步骤"]
  O["产出层：失败重试提醒"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 需要多平台内容分发的全体独立开发者与内容创作者；员工定位：一次录入、十平台分发、数据自动回捞的"分发中控台" |
| 触发层 | 关键词 / 显式点名「定时发布」；触发方式：定时 |
| 执行层 | 生成发布计划 → 调用 MultiPost 类连接器/官方 API → 失败重试提醒 |
| 产出层 | 失败重试提醒 |

## 执行流程

flowchart LR
