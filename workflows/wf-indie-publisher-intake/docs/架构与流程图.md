# 内容一次录入 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：多平台发布与数据回捞助理 的使用者"]
  T["触发层：内容一次录入"]
  X["执行层：2 个步骤"]
  O["产出层：元信息补全"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 需要多平台内容分发的全体独立开发者与内容创作者；员工定位：一次录入、十平台分发、数据自动回捞的"分发中控台" |
| 触发层 | 关键词 / 显式点名「内容一次录入」；触发方式：人工 |
| 执行层 | 主稿 + 素材录入 → 元信息补全 |
| 产出层 | 元信息补全 |
